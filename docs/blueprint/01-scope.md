# 01-scope.md - MVP Scope

## Included Features

### Landing Page
- Static homepage presenting the platform value proposition
- Basic navigation to offers and categories

### Offer Listing
- List all available offers
- Basic pagination
- Status filtering (active/expired)

### Offer Detail
- Full offer information display
- Source attribution
- Key metrics visible

### Categories/Basic Filtering
- Category listing
- Filter offers by category
- Browse by category navigation

### Offer Management
- Create/update offers (admin)
- Basic offer CRUD operations
- Status management (active/expired/draft)

### Outbound Click Tracking
- Record click events when users click offer links
- Store click timestamp and basic metadata

### CPA Conversion Tracking
- Track conversions where ad networks/supports are enabled
- Store conversion attribution

### Basic Revenue Tracking
- Aggregate revenue from converted clicks
- Basic reporting dashboard

### Basic Admin Visibility
- Admin dashboard showing platform metrics
- User/activity overview

### Basic Offer Validation
- Validate offer data on creation/update
- Required field checking
- Status assignment logic

### Basic Automated Expiration/Status Handling
- Auto-expire offers past their end date
- Status transitions based on rules

## Excluded (Future Phases)

- Mobile app
- Advanced AI recommendations
- Machine learning models
- Complex fraud detection systems
- Content generation/factory
- Advanced personalization engines
- Sophisticated analytics platforms
- Multi-service architecture
- Paid advertising optimization
